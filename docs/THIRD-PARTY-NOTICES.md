# Source and license notices

The root [MIT license](../LICENSE) covers original repository material. Third-party copyright, license and attribution notices retained in package `references/sources.md` and the dated source reviews continue to apply to their material. Keep those notices with redistributed packages. Public repository identifiers and source authorship are provenance, not recipient configuration.

The reviewed upstream repositories and exact commits are listed in [skills/catalog.json](../skills/catalog.json) and [skills/source-coverage.json](../skills/source-coverage.json). These reviews are not permission to copy assets, install executables or infer a license for an optional unbundled package. Check that package's own terms and full source before adopting it. Recipient account details, personal Guide URLs and standing grants do not belong in this public source.
