# Provider consolidation

The active procedure owner is now the [coherent skillset](SKILLSET.md), selected by [METHOD-ROUTING.md](METHOD-ROUTING.md). The former arrangement of 18 personal methods plus four optional competing suites has been superseded.

Useful techniques from the original 83 reviewed provider entries are integrated into the owned packages or their conditional references. Four independent outcomes from the additional Addy 0.6.16 review extend the active collection to 28. The [coverage record](../skills/source-coverage.json) preserves the original baseline and the new review/disposition. The reviewed Garden design material further extends the current collection to 30 methods, with two new output owners and two amended UI methods. It is provenance, not another workflow. No provider package is required to execute an owned method.

Installed provider originals remain provider-owned and can still be explicitly selected by the user. Do not edit their files, silently invoke an explicit-only wrapper, change plugin permissions or remove an app as part of normal routing. The canonical set owns default execution; a vendor meta-router does not add a mandatory lifecycle, task tracker or approval round.

Current user instructions, project contracts and actual tool authority stay authoritative. Preserve existing quality floors, unrelated work and actual runtime acceptance. A static example/helper or vendor benchmark is not project proof.
