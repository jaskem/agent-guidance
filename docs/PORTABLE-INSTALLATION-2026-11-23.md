# Portable workflow installation

## Result and ownership

The requested source change makes adoption recipient-neutral and routes AI agents from `README.md`, `AGENTS.md` and the method router into `INSTALL.md`. The implementation supports durable files/Git, an explicitly selected Notion workspace, supported native skill hosts and pinned repository consumers. Reading the repository alone does not install anything or authorize account changes.

Original repository work is MIT licensed following the owner's explicit choice. Required upstream source/license attribution remains. Concrete private Guide URLs, source-machine locators, account-linked consumer inventories and grant details are removed or explicitly redacted from current public source. Git history is retained; this is not historical data erasure.

`INSTALL.md` owns bootstrap/reconciliation; adapter documents own destination details. Templates contain recipient placeholders. A selected immutable snapshot supplies versions, counts and full package content. Optional external packages are unbundled integration contracts with usable base/public fallbacks. They confer no recipient permissions or assumed installation.

## Limits and recovery

Structural checks are not personal-name recognition, proof of semantic neutrality, source authenticity or host-wide enforcement. Source/legal names and public repository identifiers are intentional attribution. No real recipient Notion/native installation or automatic loading in a new host session was observed. File-trial targets are isolated acceptance environments, not durable real-user deployments. Historical measurement redactions reduce public reproducibility and do not manufacture replacement measurements.

Publication is through the existing PR; source merge and CI results are recorded there and at the configured private work owner. Recovery reverts only this source batch to the accepted baseline and runs affected checks. Do not reset consumer repositories, alter private setup versions or restore unrelated user files. Recipient installations use their own saved bounded recovery record; source publication does not migrate them automatically.
