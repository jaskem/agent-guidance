# Composition recipes

Use these small patterns after the brief is known. Select only fields that affect the result; examples are not factual defaults or aesthetic requirements.

## Product visual

Establish whether the image is an atmospheric product scene, a faithful presentation of an existing object or an explicitly fictional concept.

Record:

- the verified product/model and reference views;
- visible geometry, finish, distinctive features and components that must remain;
- camera position, crop and any room required for surrounding copy;
- consistent light direction, contact shadows and reflections;
- any supplied component labels and the object each label identifies.

For an exploded view, obtain the component list, order and connection logic from actual evidence. Keep the same part identity and plausible alignment across assembled and separated states. Do not invent a component count or technical benefit to fill a layout. When the purpose requires accurate engineering structure, use the actual model or an exact drawing workflow instead of a generated reconstruction.

## Campaign or asset series

Separate shared constants from deliberate variation.

| Shared constants | Per-asset choices |
| --- | --- |
| Supplied brand/product identity, palette, typography character, material language and tone | Particular message, scene, crop or composition under comparison |
| Agreed output dimensions and usable safe areas | Supplied asset-specific headline or call to action |
| Reference product or character attributes | Intended pose, angle or setting |

Make each asset useful on its own when that is the deliverable. Keep comparable optical size and presentation quality when showing alternatives. Preserve supplied marks through a suitable exact application workflow when fidelity is essential; a generated reinterpretation is not the original mark.

Do not add slogans, prices, promotional claims or fictional customer proof merely because a campaign template contains those fields. Include only the requested copy or clearly labelled creative proposals within scope.

## Storyboard or state sequence

Define the narrative/state order and the subject identity before describing individual panels. Use as many beats as the requested story needs, with no preset grid.

For each beat record:

- its identifier and intended reading order;
- what is happening now and what changed since the previous beat;
- the recognizable subject and important fixed appearance;
- framing or viewpoint where it communicates the action;
- supplied narration/copy or timing when it actually exists.

Keep location, object state and lighting continuous unless the story deliberately changes them. A change of camera does not authorize a different product or character. A storyboard depicts a proposal; it is not evidence of rendered motion, audio timing or a working interaction.

## Multi-region visual board

Define a primary focal region and the supporting regions needed to explain it. Name each region's purpose, content, priority and relative placement. Give labels one unambiguous destination and leave practical space for them.

For comparison boards, distinguish:

- one subject shown across states;
- different design candidates shown in matched conditions;
- independent pieces assembled for overview.

Do not mix those relationships accidentally. Check that all panels contribute and that each remains readable at the actual display size. Reduce secondary material or split the output when a single board cannot preserve the required information.

## Inspection checks

Inspect the actual generated output, not just the prompt or caption.

| Check | Observable evidence |
| --- | --- |
| Subject and reference fidelity | Compare visible features with the supplied source; identify any changed identity or geometry. |
| Region hierarchy | Confirm the first reading, intended path and spacing around the important content. |
| Text | Read exact words, spelling and label associations in the actual output. |
| Series consistency | Compare fixed attributes, scale, color and the intended differences across assets. |
| Sequence continuity | Inspect subject state and changes in the specified order. |
| Product plausibility | Check visible connections, materials, shadows and impossible intersections against actual evidence. |
| Technical scope | Verify actual alpha/export properties only with suitable observed evidence; distinguish raster exploration from source artwork. |

Separate a visual defect from a missing fact. Fix the former through a targeted edit; resolve or disclose the latter. Do not promise pixel-identical preservation from a generative operation or call a generated concept production-ready without the required source and export checks.
