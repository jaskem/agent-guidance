# Sources and adaptation

Canonical source: jaskem/agent-guidance, skills/image-art-direction. Package version: 1.1.0. Personal and Notion copies are distributions of this source.

This is an original, provider-neutral synthesis for complex raster-image art direction. It is not an unchanged installation of Garden gpt-image-2, and it does not include or require Garden's runners or complete template library. The native image-generation capability owns execution and its current tool contract.

Reviewed upstream: [ConardLi/garden-skills](https://github.com/ConardLi/garden-skills/tree/f2d7adeaf53dcce3d0eb19cbffe8c04f4c636c2a), revision f2d7adeaf53dcce3d0eb19cbffe8c04f4c636c2a, inspected on 2026-11-20. The gpt-image-2 manifest at this revision declares version 1.0.4.

Retained techniques: bounded region hierarchy, explicit reference roles, fixed versus varying attributes, subject continuity, readable actual output, and targeted revisions.

Intentional adaptations: preserve the user's accepted brief and factual evidence; avoid mandatory interviews, fixed quotas and default aesthetics; use native generation without credential discovery or external gateways; route exact factual diagrams/charts and live interfaces to suitable tools; retain logo-design as the identity owner. The package is self-contained and does not claim review of every upstream template.
