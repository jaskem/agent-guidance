# Learning records

Reuse an existing learning page rather than constructing a second course tree. Record a practical goal, relevant source/revision and only durable evidence of learning: a demonstrated explanation, solved exercise, stated prior knowledge or corrected misconception. Qualify self-reported knowledge as such.

Do not record merely covered material as learned. Keep personal learning status separate from the project glossary, whose terms remain authoritative whether or not the learner has mastered them. Link definitions rather than copying competing ones.

When a later observation changes the understanding, mark the earlier record superseded. Avoid full transcripts, sensitive personal details and session activity logs. If storage is unavailable, deliver the explanation and report that notes were not saved.
