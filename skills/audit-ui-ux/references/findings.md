# Finding record

Use stable IDs and concise records.

- Target task and view/state.
- Evidence: image and region or exact source location; version, viewport and limitations.
- Observation: directly visible or reproduced condition.
- Interpretation: likely task consequence, explicitly a hypothesis where untested.
- Priority: P0 demonstrated task block/data-loss path; P1 substantial task difficulty; P2 recurring friction/discoverability; P3 visual refinement.
- Confidence: high for direct observations, medium for plausible interpretation, low for an open question.
- Recommendation and meaningful trade-off.
- Acceptance: concrete before/after condition, plus validation method.
- Owner: existing task or proposed next action.

Severity and confidence are independent. Unknown behavior is a check to perform, not a defect. Record capture freshness, synthetic data and absent states. Group repeated symptoms instead of inflating counts. Preserve strengths and leave an inspectable route to validation.
