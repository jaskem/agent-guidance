# Grill a plan

## 1. Recover the plan and requested interview

Follow the user's configured operating guide once per session and its active tool-call version. Reuse verified context and read the relevant plan, source owners, constraints and accepted decisions. If no plan or decision is identifiable, ask only for that topic. Ordinary questions and authorized implementation alone do not start this interview.

Use available agents without waiting for an explicit user request when this method calls for independent fact-finding or when a bounded parallel task or separate check would improve the result. Follow the routed delegation procedure; give each worker a source/revision, scope, allowed actions and expected evidence. Keep one writer per shared object, use the current host capabilities and let the parent verify and integrate the result. If delegation is unavailable, continue supported work and state any required independence that remains unproven.

## 2. Find the ready questions

Map the material unresolved choices and their prerequisites using [dependency-aware rounds](references/rounds.md). Recover accessible facts from sources; use independent agent fact-finding when called for. Keep settled answers and distinguish an investigation from a decision only the user can make. If a source is unavailable, expose the missing prerequisite instead of inventing its answer.

## 3. Interview in useful rounds

Ask a short numbered round of ready questions in the user's language. Give the recommended answer and material consequence of each choice. Wait for the answers before asking dependent questions; continue independent source investigation meanwhile. Recompute the frontier after each round and probe a concrete case when an answer leaves a material ambiguity. Do not reopen decisions merely to complete a template.

## 4. Confirm shared understanding

Summarize settled decisions, reasons and the exact remaining prerequisites at the established plan or conversation. Ask the user to confirm that this captures the shared understanding. Save authorized durable decisions only after reading the destination and verify uncertain writes. A blocked prerequisite remains open; no question round, saved summary or this skill alone authorizes implementation, publication or a new tracker.

Read [sources and adaptation](references/sources.md) when maintaining this package.
