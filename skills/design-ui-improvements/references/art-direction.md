# Art direction for a bounded interface proposal

Reuse accepted choices. A precise repair needs no new style exercise. Establish audience, task, platform, viewport, actual content and identity at the existing owner. For a new experience, use supplied requirements and label the result a proposal; never invent observations about an absent baseline.

## Choose the smallest design mode

- Extension: make the new element belong to the existing system.
- Preserve: improve the interface while retaining accepted identity and useful behavior.
- Overhaul: introduce another visual language only within authorized scope.

Keep task routes, information, user content, state/persistence, accessible behavior and integration contracts explicit. A design mode adds no implementation authority.

## Make five choices consequential

Use descriptive choices or concrete values, without decorative scores.

| Choice | Lower setting | Higher setting | Observable consequence |
| --- | --- | --- | --- |
| Visual variance | Familiar, stable composition | Exploratory hierarchy/composition | Where layout may depart from established patterns |
| Motion | Direct state feedback | Sequenced or spatial storytelling | Which meaning depends on timing and how reduced motion works |
| Information density | One idea with reading pauses | Operational comparison and editing | Useful content visible, grouping, widths, row heights and disclosure |
| Asset dependence | Type, data and structure carry the work | Imagery or demonstrations carry recognition | Required real assets and honest missing-asset boundaries |
| Identity fidelity | Exploratory identity | Close match to accepted language | Which tokens, components, assets and behavior stay fixed |

For dense work, stabilize navigation and grids before adding variation. Animate a meaningful transition, not every item. For a faithful extension, inspect actual product tokens and components rather than importing a reference palette.

## Select a direction when needed

Prefer supplied systems, actual materials and accepted references. Without a direction, compare the smallest useful set of meaningfully different proposals and recommend by task fit. No fixed number of variants or additional approval sequence is required.

| Direction | Useful context | Decisions to explore | Guardrail |
| --- | --- | --- | --- |
| Information led | Analytical tools and comparisons | Stable grids, aligned data, direct labels, semantic color | Preserve legibility and hierarchy as density increases |
| Editorial restraint | Reading, portfolios, product presentation | Type hierarchy, image treatment, line length, pauses | Gallery spacing does not suit every frequent task |
| Builder tool | Productivity and expert applications | Compact chrome, clear states, separators, keyboard paths | Use actual product identity, not a copied dark theme |
| Motion led | Demonstrations and explanations | Meaningful reveals and spatial relationships | Preserve control, performance and reduced-motion completion |
| Raw or structural | Content-first publishing and unusual identities | Direct structure, typography, limited ornament | Restraint must not obscure controls or resemble broken styling |
| Warm humanist | Community, education and services | Tone, illustration, material, type character, supportive feedback | Decoration must support the task |

These are working lenses, not official specifications of named brands or designers. Named anchors and Garden's style recipes are interpretations. Inspect current source materials before claiming official fonts, colors or behavior. Recipes supply inspiration, not product facts or binding values.

## Make direction inspectable

Specify necessary surfaces, type roles, accents, spacing, component sizes, assets and motion. Make each important choice visible in the artifact. Show an early rendered slice when it resolves uncertainty and continue ready authorized work. Use visual comparisons for visual choices and an executable prototype for uncertain behavior; keep experimental controls out of product UI unless requested.

Check content fit, oversized regions, clipped labels, empty filler, repeated containers, inaccurate product imagery and inconsistent states. Compare equivalent tasks and data at the same scale. Preserve useful familiar controls and fonts rather than seeking novelty for its own sake.

Finish with the direction, task rationale, protected behavior, inspected artifact and remaining evidence limits. An implemented result still needs appropriate real rendering and interaction evidence.
