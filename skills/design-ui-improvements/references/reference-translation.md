# Translate references into this product

Classify each source before borrowing from it. A product reference informs hierarchy and visual language; an interaction reference needs observed action → object change → feedback → resulting state. Keep screenshots, live behavior, source tokens and interpretation separate. A generated mockup is a proposed view, not evidence of an existing application.

For faithful reproduction, establish image pixel size, logical viewport, zoom and device-pixel ratio when available. Do not equate screenshot pixels with CSS pixels. Compare structural ratios, alignment, type hierarchy, density and representative states at matched scale; disclose unknown scale instead of claiming pixel accuracy. Style borrowing preserves the actual product task and content rather than copying a whole layout.

Write a short keep/add/remove intent for a consequential redesign. Compare the baseline and alternatives with equivalent data, viewport and asset quality. Do not make one direction artificially weaker with placeholders or blur. Use generated imagery only when the job calls for it; exact UI belongs in code/vector/native layout. No universal row height, card padding, color ratio, prompt length or animation count is a design standard.

Treat third-party DESIGN.md collections as dated observational references, not official brand specifications or installable skills. Resolve a supplied first-party design system before a curated interpretation. Extract only relevant semantic tokens, typography roles, spacing/density, component/state rules and asset/motion intent into the product's existing design owner. Label measured values, supplied values and proposed choices separately. Check fonts/assets and permissions at their source, inspect actual light/dark and interaction states when claimed, and avoid inventing unobserved responsive behavior.

If a reusable cross-medium system is requested, pass these decisions to design-brand-system. Ordinary interface improvements remain here. Check the rendered result on the selected relevant surface and keep unavailable comparison states explicit.
