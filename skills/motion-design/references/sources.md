# Sources and adaptations

Canonical owner: jaskem/agent-guidance, skills/motion-design. Package version: 1.0.0. Personal and Notion packages are distributions.

Original synthesis of reviewed procedures, inspected on 2026-11-20. No upstream code, runtime scaffolds, installers, private router APIs or complete libraries are bundled.

- [iart-ai/motion-skills hub](https://github.com/iart-ai/motion-skills/tree/e8ba1f4eb2bcca3d1639d7545b9cd2bcfe4a3c6f) indexes separate packs; the hub itself contains no SKILL.md. The source review records the distinct pack pins and actual reading coverage.
- [iart-ai/web-animation-skills](https://github.com/iart-ai/web-animation-skills/tree/ed3a045192679b24d32090ee7a983871311ababd): state/presence ownership, lifecycle cleanup, layout/scroll recalculation, SVG, playback and accessibility branches. Current platform APIs must be verified for the target runtime before use.
- [iart-ai/webgl-animation-skills](https://github.com/iart-ai/webgl-animation-skills/tree/0041933813688c357804f7b13dcb85095c5a3210): scene/loop/resource ownership, responsive renderer limits and deterministic export boundaries.
- [zstvns motion-design](https://github.com/zstvns/design-skills/tree/771fdf3c90c6877d5c193cbc80dae23b5590c037/skills/motion-design): functional versus expressive purpose, identity, directional origin and repeated-use restraint. Fixed timings, blanket property/easing prohibitions, compulsory brand cascade and tool preferences are excluded.
- [Oil UI](https://github.com/oil-oil/oil-ui/tree/81f2657f41410f04ae47ba77f902fcc0567eaab2): actual user-triggered response, scroll distinction, interrupted transitions and final-state verification. Fixed motion quotas and image-first workflow are excluded.

Timed film production stays with visual-storytelling; logo construction stays with its existing owner. Reduced motion preserves meaningful state, and every performance or interaction claim needs actual runtime evidence. A tool or module being present does not prove its capture, input or export path works.
