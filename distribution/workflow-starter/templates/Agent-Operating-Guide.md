Read this Guide once per session when the host routes here. Load the pinned kernel, work cycle and relevant method content. Use direct handling for simple questions. Project work follows the own index to verified source/task owners; preserve repository-local pins. Reuse valid context and refresh affected mutable sources before changing them.

Use the accepted setup-instruction version for the chosen service; never upgrade it silently. Optional services, external packages and historical grants are not active merely because the source mentions them. Delegate only within the current user/host authority and supported capabilities. Keep one writer per object and verify integrated results.

Save durable facts only within the user's own permissions and destination choices. For scheduled or continuous maintenance, record the actual user grant and registered schedule separately; absence means not configured. A failed read blocks only dependent actions and is reported precisely. No source template guarantees automatic loading by every host.
